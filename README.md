Install: unzip it, open edge://extensions/, turn on Developer mode, click Load unpacked and select the feedback-autofill folder. If you installed the earlier version, remove it first.

Use: log in, pick a subject, then pick a faculty member. When the questions appear the form fills itself within a second and a green “auto-filled” note shows briefly. You then type the captcha and click Submit. Do the same for each subject and faculty member.
